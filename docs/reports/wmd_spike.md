# 词组合推理（WMD 式）spike 报告：wmd_cos 特征 × cheap 档 A/B

**分支**：`dev-2.0`｜ **定位**：非-LLM 路线收尾实验（词→句桥梁的最后一种形态）
**判决（预注册）**：CV/泛化 Δ ≥ +0.02 → 成立进引擎集成；< +0.02 → 证伪归档。
**实测判决：证伪归档**——CV AUC Δ = **0.000**，重放 +0.036 为全量训练内样本效应。

---

## 1. 实现与披露口径（bench/scripts/wmd_eval.py）

- **词向量源**：bge-small-en-v1.5 int8 onnx（复用 svec_eval 分词/推理）；
  token 向量 = **最后一层 hidden state 中该 token 的上下文向量**（去 CLS/SEP，
  逐 token L2 归一）。披露：bge 的 token 级表示无专门训练目标（MLM 之外），
  质量预期一般——实测证实（见 §3）。
- **wmd_cos**：两侧分词 → 去停用词（30 词英语表，**两侧同口径**）→ 各截
  ≤30 token → **贪心最佳配平**（每轮取余下词对余弦最大者配对）→
  `wmd_cos = (Σ配对cos − 0.2·未配数) / max(n_q, n_c)`。
  贪心近似声明：非精确 OT（运输问题最优解）；30×30 规模下贪心界松，但本
  spike 判的是"词组合路线有无信号"，近似误差不改判决方向（CV Δ=0 是
  特性消失而非噪声掩盖——逐折 Δ∈{+0.002,+0.002,+0.002,+0.002,-0.005}）。
- **token 向量磁盘缓存**：`bench/models/cache/tok/{sha1(模型|tok|文本)}`
  （.npy 向量 + .json token 名；复跑 408/408 全命中，秒级）。
- **接入**：cheap_rerank_train 框架 12 特征（11 cheap + wmd_cos，题内
  minmax 与引擎口径一致）；同折 5-fold 对照 base(11) vs wmd(12)。

## 2. 对照与判决

| 项 | base（cheap 11 特征） | cheap+wmd（12 特征） | Δ |
|---|---|---|---|
| **5-fold CV AUC（泛化，判决指标）** | 0.710 [0.701/0.774/0.761/0.654/0.659] | 0.710 [0.704/0.776/0.763/0.656/0.654] | **+0.000** |
| 全量训练重放覆盖率（内样本，参考） | 0.547（29/48） | 0.583（31/48） | +0.036（非泛化） |
| 学出 wmd_cos 权重 | – | +0.412 | – |

- **判决：CV Δ = 0.000 < +0.02 → 证伪归档**，不进引擎集成（C++ 零改动）。
  重放 +0.036 是 42 训练题全量拟合后的内样本效应（与 svec 当时 CV
  +0.072/重放 +0.114 的"双升"模式对比：真信号两指标同向，假信号只有
  内样本升）——这正是把 CV 设为判决指标的原因。
- 对照链：svec_cos 当时 CV AUC 0.710→**0.782**（真特征）；wmd_cos
  0.710→0.710（零增量）。

## 3. 附带测量

- **tau（wmd vs LLM 教师选中集，B 类口径 37 题）**：**+0.108**——svec 同口径
  +0.216 的半数；词组合排序离教师比句向量更远。
- **wmd_cos vs svec_cos 逐题 Pearson：+0.402**（n=50）——中等正相关，非冗余
  但也不互补：两者共享 bge 表示的同一信息面，wmd 的"组合"没有带来
  svec 之外的独立信号（CV Δ=0 的结构性解释）。
- **结论链闭环**：六轮非-LLM 探索（词级 graded 边 → cheap 特征学习
  [唯一成功者，AUC 0.71/judge 可用] → formula 七关系线性路由[无贡献]
  → svec 句向量[离线有信号/引擎边际小] → WMD 词组合[零信号]）——
  **词→句的桥梁在"无 LLM、小编码器"约束下结构性不通**：bge-small 的
  token/句表示携带的语义不足以支撑检索排序，无论池化（svec）还是
  配平（wmd）形态；有效的是**引擎结构特征 + 学习权重**（cheap 档）。

## 4. 蓝方自检

1. **token 表示选择**：上下文向量（非额外均值）已披露；bge token 质量
   预期一般 → 实测 tau 仅 svec 半数，预期兑现。
2. **贪心 vs 精确 OT**：声明贪心近似；判决不依赖近似精度（逐折 Δ≈0 的
   一致性说明是信号缺失不是求解噪声）。
3. **缓存键**：sha1(模型目录名|tok|文本)，与句向量缓存（kind 分域）不撞；
   复跑 408/408 命中零推理。
4. **停用词口径**：同一 30 词表双侧应用；截断 ≤30 双侧同规则。
5. **复现确定性**：三轮运行数字逐位一致（分词/向量/配平全确定性）。
6. **纪律**：CV 为唯一判决指标（重放明示为内样本参考）；<+0.02 不集成
   （C++ 零改动，ctest 状态不变——test_bench 155/155 为最近绿基线）。
