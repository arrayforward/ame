# P3a lmem miss 分类诊断（sample50，D1 预固定判决标准）

> 数据：LoCoMo sample50（有金标 n=48）；管线：--store lmem 基线模式，
> 候选池 = Mem.recall 输出（k_pool=60，终排 BM25-lite 之前），与正式取证同一口径。
> **规范口径 = P2 管线**：本报告由最终 commit 加 `--prox-window 0 --no-expand` 复现
> （P3b 通道关闭时与 P2 逐比特等价，test_lstore ⑦ 验证）——P3a 先行于 P3b，
> 判决不受 P3b 落地影响；post-P3 观测口径见 miss_taxonomy_postp3.json。
> 判决标准（D1 预固定，先于 P3b/c 实现锁定）：A 改述鸿沟 = 候选池无金标 且
> 问题↔金标轮最大词面重合度 < 0.05；B 排序出局 = 候选池有金标
> 但终排 top-k=10 证据无金标；C 其他（含重合度≥阈值仍无金标 = 召回通道漏召回）。
> 词面重合度 = |tok(q) ∩ tok(gold)| / |tok(q)|，分词逐字节复刻 memindex_tokenize（CJK 二元组 + ASCII 小写词）。
