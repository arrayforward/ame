# AME 文档索引

联想记忆引擎（Associative Memory Engine）的两份核心文档，建议按下列顺序阅读：

1. **[设计文档](design/联想记忆引擎设计文档.md)**（design/，含 7 张架构图）
   1.x 设计冻结版：设计哲学、数据模型（双骨架与桥）、模块划分与接口定义、
   recall 管道、深度思考、写入与消歧、学习化流程。理解系统"为什么长这样"从这里开始。
   **3.0 注记**：M8/M11/M14 与 2.0 分层存储已裁（文首有修订说明、被裁节就地标注）；
   [AME2.0 分层架构设计](design/AME2.0_分层记忆架构设计.md) 为已裁撤归档稿，
   现行架构以仓库 README"3.0 简化版"节为准。

2. **[工程实现与优化文档](engineering/联想记忆引擎_工程实现与优化文档.md)**（engineering/）
   设计文档的工程侧配套：C++17 实现路线、工程规范、三基准（LoCoMo / LongMemEval / BEAM）
   适配方案、评测结果记录、已定位问题与修复、优化方法论、语义增强（词典蒸馏）、
   实体档案、后续路线。理解代码"怎么落地、调过什么、结论如何"看这份。

3. **[基准评测报告](reports/README.md)**（reports/）
   LoCoMo 与 LongMemEval 的评测报告与失败分析归档：全量指标、分题型/分 category
   数字、两个失败点的根因链与修复 A/B、已否证假设存档、评测方法论（指标口径/
   缓存复跑/逐题失败分析方法）。查"跑得怎么样、为什么差、怎么修的"看这里。

仓库根 [README](../README.md) 提供编译说明与快速上手；词典文件的获取与转换方式见 [lexicon/README](../lexicon/README.md)。
